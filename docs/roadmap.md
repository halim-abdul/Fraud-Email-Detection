# Research roadmap

1. Obtain permissioned, labelled enterprise email data and establish a time-separated holdout.
2. Add URL/domain reputation through a privacy-reviewed enrichment service.
3. Compare calibrated ML models and measure per-class errors and adversarial robustness.
4. Integrate LLM summaries in a locked-down provider with consent, DLP and content isolation.
5. Build an auditable review-and-approval queue with no autonomous send privileges.
6. Validate workflow version compatibility and continuous authentication monitoring.
7. Enable multi-tenant controls, PII retention rules and incident response runbooks.
